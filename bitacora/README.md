# Bitácora del proyecto

La bitácora registra las sesiones de trabajo relevantes de CORA DAYCARE. Sirve para saber qué se decidió, qué se hizo y qué sigue, sin tener que reconstruirlo después.

## Cómo funciona (formato híbrido, D-47)

1. **Una entrada por sesión relevante.** Cada entrada es un archivo `.md` en esta carpeta, con el nombre `AAAA-MM-DD_NNN.md` (fecha y número consecutivo). Es la fuente de verdad.
2. **Un índice.** La tabla de abajo lista todas las entradas. Se actualiza en el mismo commit que agrega la entrada.
3. **Un PDF al cerrar cada fase.** Al terminar una fase se compila un PDF con sus entradas y se guarda en `entregables/`.

Para escribir una entrada, se copia [`_plantilla.md`](_plantilla.md) y se llena.

## Reglas

- Una entrada por sesión relevante, no por cada cambio pequeño.
- Cada decisión lleva su identificador (D-xx) y cada pendiente el suyo (P-xx), como en el documento de Identidad.
- Solo nombre y un apellido de cada integrante; sin matrículas, correos ni teléfonos (D-40).
- Lo que se escribe aquí lo puede leer cualquiera, porque el repositorio es público (D-45).
