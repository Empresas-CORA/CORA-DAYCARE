# 03 · Diseño

Esta carpeta guardará la documentación de la fase de Diseño de CORA DAYCARE: arquitectura de los cinco frentes (web, móvil, IA, IoT y ciberseguridad), modelo de datos, interfaces, plan de seguridad y plan de pruebas.

Para el primer entregable (1 de diciembre de 2026) se redacta su versión esencial, que incluye web y móvil: arquitectura de los cinco frentes, modelo de datos, diseño de seguridad, especificación del brazalete y wireframes. El plan de pruebas y de despliegue se completa después. Se parte de lo definido en [`docs/02-analisis/`](../02-analisis/).
