# 02 · Análisis

Esta carpeta guardará la documentación de la fase de Análisis (requerimientos) de CORA DAYCARE: requisitos funcionales y no funcionales, requisitos de seguridad y privacidad, e historias de usuario.

Para el primer entregable (1 de diciembre de 2026) se redacta su versión esencial: requisitos funcionales y no funcionales, requisitos de seguridad y privacidad, historias de usuario por rol y trazabilidad a los objetivos O1 a O5. La validación con usuarios y la asesoría legal se completan después. Se parte de lo definido en [`docs/01-planificacion/`](../01-planificacion/).
